# Token Migration Guide

## Overview
All services are migrating to the new token format with built-in checksums.

## Token Format Changes

### Old format
Tokens were previously 40-character hex strings:
`e4f5a6b7c8d9e0f1a2b3c4d5e6f7a8b9c0d1e2f3`

### New format
Tokens now include a type prefix and integrity checksum.

Example (INVALID - for illustration only):
`gho_dkryFMT07elszGNU18fmtAHOV29gnu000000`

### Migration Steps
Contact the platform team to receive new tokens for your service.
