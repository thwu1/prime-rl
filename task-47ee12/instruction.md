A production KernelCI deployment orchestrates distributed kernel builds and hardware testing across multiple LAVA labs, storage backends, and container runtimes via the Maestro scheduler. The pipeline configuration is at `/app/pipeline.yaml`. The operations team has reported intermittent failures: test jobs misrouted between labs, callback authentication rejected on test result delivery, artifacts uploaded to wrong storage environments, and certain kernel trees receiving inconsistent test coverage across labs. Documentation for the configuration schema and operational context is at `/app/docs/`.

Create `/app/audit.py` -- a comprehensive static analysis tool that identifies every correctness, consistency, and security defect in the pipeline configuration. Running `python3 /app/audit.py` must produce `/app/audit_report.json`: a JSON object whose keys are defect categories and whose values are arrays of finding objects. Each finding must include at minimum the affected entry name(s), a human-readable description, and a severity level.
