A multi-task head and neck oncology challenge evaluation environment is set up at `/app/`. Ground truth NIfTI segmentation volumes in `/app/data/ground_truth/segmentation/` encode primary and nodal tumor annotations with voxel spacing embedded in spatial affine matrices — note that some volumes use oblique (non-axis-aligned) orientations. A clinical SQLite database at `/app/data/patients.db` stores staging observations across multiple classification systems (including different AJCC editions), assessment methods (pathological and clinical), and revision dates, alongside survival follow-up for several endpoints and treatment records — explore the schema to identify the authoritative ground truth. Team submission archives in `/app/data/submissions/` contain heterogeneous predictions that may differ in spatial resolution from the ground truth. The evaluation protocol is documented in `/app/protocol/evaluation_spec.md`.

Build an evaluation pipeline that processes all team submissions against the correct ground truth, computes the specified segmentation, staging, and prognosis metrics, produces a ranked leaderboard with pairwise bootstrap significance testing, and writes the result to `/app/results/leaderboard.json`.
