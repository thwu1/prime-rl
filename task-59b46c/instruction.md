Synthetic multi-subject EEG motor imagery data is generated by `/app/eeg_data.py`. Each subject's neural signals are produced through subject-specific spatial mixing matrices, channel scaling, and noise profiles, simulating the realistic inter-subject variability found in brain-computer interface (BCI) research. The task is binary classification between two motor imagery conditions.

Implement the `decode(dataset_params: dict) -> dict` function in `/app/pipeline.py`. This function must:

- Generate data via `eeg_data.generate_dataset(**dataset_params)`
- Evaluate using leave-one-subject-out cross-validation: for each subject, train on all remaining subjects and test on the held-out one
- Return a dict with keys `"accuracies"` (list of per-subject float), `"mean_accuracy"` (float), and `"predictions"` (list of per-subject predicted label arrays)

The central difficulty is cross-subject generalization: each subject's signals arise from different spatial projections and noise characteristics, so approaches that ignore this variability will perform poorly. Your pipeline must overcome this distributional mismatch while extracting features that capture the class-discriminative structure in the data.

Study `/app/eeg_data.py` carefully — understanding how class-separable sources are generated and spatially mixed per-subject is essential for designing an effective decoding approach.

Dataset parameters and minimum accuracy requirements are specified in `/app/config.json`. The pipeline will also be tested on dataset configurations beyond those in the config (different subject counts, channel counts, signal lengths, and random seeds), so it must generalize rather than overfit to one specific parameterization.
