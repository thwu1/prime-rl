`/app/problem.json` defines a Lotka-Volterra predator-prey system with parameters, initial conditions, time span, and solver configuration (step size, prior order).

Implement a probabilistic ODE solver that produces posterior mean trajectories and calibrated uncertainty estimates. Run a multi-resolution convergence study and persist all results across four output formats, including an HDF5 scientific data archive and a gnuplot-generated convergence plot.

### Outputs

**SQLite database** `/app/results/benchmark.db` with tables:

- `trajectory` — columns: `step_idx INTEGER, time REAL, dim INTEGER, mean REAL, std REAL`. One row per (time step, ODE dimension) pair for the primary solution using the step size from `problem.json`.
- `convergence` — columns: `step_size REAL, terminal_rmse REAL, num_steps INTEGER`. One row per step size in `{0.04, 0.02, 0.01, 0.005}`. Terminal RMSE measured against a high-precision reference must decrease as step size decreases.
- `metadata` — columns: `key TEXT PRIMARY KEY, value TEXT`. Required keys: `output_scale`, `solver_type`, `prior_order`.

**HDF5 archive** `/app/results/trajectory.h5` with hierarchical structure:

- Group `/trajectory` containing datasets:
  - `times` — shape `(T,)`, float64
  - `mean` — shape `(T, d)`, float64
  - `std` — shape `(T, d)`, float64
  - All three datasets must use gzip compression (compression level >= 4) and chunked storage.
- Group `/metadata` with HDF5 attributes (not datasets): `output_scale` (float), `solver_type` (string), `prior_order` (int), `num_steps` (int).
- Root-level attribute `schema_version` with value `"1.0"`.

**JSON summary** `/app/results/summary.json` with keys: `terminal_mean` (list), `terminal_std` (list), `output_scale` (positive float), `num_steps` (int).

**Gnuplot convergence plot** `/app/results/convergence.svg` — an SVG image generated by gnuplot (not matplotlib or other tools; gnuplot is pre-installed at `/usr/bin/gnuplot`). The plot must be a log-log scatter of step size vs. terminal RMSE from the convergence table, and must include:

- A reference slope line showing the expected convergence order (based on the prior order from `problem.json`).
- Title containing "Convergence".
- Axis labels for both axes.

### Acceptance criteria

- Initial condition: mean at t=0 matches `problem.json` values.
- Terminal RMSE < 0.05 against high-precision reference.
- Midpoint and quarter-point RMSE < 0.1 against reference.
- All solution values strictly positive.
- Calibrated standard deviations: positive after initial time, finite everywhere, must vary over time.
- Lotka-Volterra first integral V = delta*y1 + beta*y2 - gamma*ln(y1) - alpha*ln(y2) must drift < 0.5 over the full time span.
- `output_scale` positive and finite; `num_steps` within +/-5 of expected count.
- Time grid: at least 100 points, first time within 1e-6 of `time_span[0]`, last within 0.02 of `time_span[1]`.
- Trajectory table row count equals T * d from `trajectory.h5`.
- Terminal values in `summary.json` consistent with final row of `trajectory.h5`.
- HDF5 datasets gzip-compressed with correct hierarchy and attributes.
- SVG convergence plot generated by gnuplot with log-log axes, reference slope, title, and axis labels.
