# Mathematical Specification: Euler Deconvolution for Gravity Source Location

## Point-Mass Gravity

The downward gravitational acceleration at observation point (x, y, z) from
a point mass m located at (x_s, y_s, z_s), with z positive upward:

    g_z(x, y, z) = G * m * (z_s - z) / r^3      [m/s^2, multiply by 1e5 for mGal]

    r = sqrt((x - x_s)^2 + (y - y_s)^2 + (z - z_s)^2)

G = 6.674e-11 m^3/(kg*s^2). For a source at depth h below the surface,
z_s = -h, and at z = 0:

    g_z = G * m * h / r^3 * 1e5     [mGal]

## Euler's Homogeneity Equation

A potential field f generated by a simple source at (x_0, y_0, z_0) with
structural index eta and base level b satisfies:

    (x - x_0) df/dx + (y - y_0) df/dy + (z - z_0) df/dz = eta * (b - f)

where df/dz is the derivative in the upward (+z) direction.

### Structural Index Values (Gravity)

| Source geometry          | eta |
|--------------------------|-----|
| Point mass / sphere      |  2  |
| Line mass / cylinder     |  1  |
| Thin sheet edge          |  0  |

## Linear System Formulation

For n observations at z = 0, rearrange Euler's equation to solve for
p = [x_0, y_0, z_0, b]:

    A * p = d

where:
    A_i = [df_i/dx,  df_i/dy,  df_i/dz,  eta]       (n x 4)
    d_i = x_i * df_i/dx + y_i * df_i/dy + eta * f_i  (n x 1)

Solve by ordinary least squares: p = (A^T A)^{-1} A^T d.

Source depth = -z_0 (positive for buried sources since z_0 < 0).

The residual covariance C = sigma^2 * (A^T A)^{-1}, where
sigma^2 = ||d - A p||^2 / (n - 4), provides a solution quality metric.

## Vertical Derivative from a Horizontal Grid

The upward derivative of a field measured on a horizontal plane at z = 0
can be computed in the frequency domain:

    F{df/dz_up} = -|k| * F{f}

where |k| = 2 * pi * sqrt(f_x^2 + f_y^2) is the radial wavenumber
(f_x, f_y are spatial frequencies in cycles/m).

Implementation:
1. Pad the grid (e.g. 50% each side, edge-replicate) to reduce edge artifacts.
2. Compute 2-D FFT of the padded grid.
3. Multiply element-wise by -|k|.
4. Inverse FFT and take the real part.
5. Trim padding.

Horizontal derivatives df/dx and df/dy should be computed with central
finite differences on the discrete grid.

## Sliding-Window Strategy

1. Choose a rectangular window (e.g. 8-15 grid cells per side).
2. Slide the window across the grid with a chosen step size.
3. At each position, form A and d from the windowed data and solve.
4. Collect all solutions.

## Solution Filtering and Clustering

Reject solutions that:
- Have non-physical depth (z_0 > 0 or depth > survey extent).
- Fall outside the survey boundaries.
- Have large covariance trace (poorly constrained).

Cluster the remaining solutions by spatial proximity and compute the
median position of each cluster to estimate individual source locations.
