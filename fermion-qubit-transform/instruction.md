A quantum chemistry project at `/app/` computes ground state properties of Hubbard model systems using a `Makefile`-based workflow. The project was abandoned in a broken state with bugs in the Python source code, a misconfigured YAML file, and a broken `Makefile`.

The project includes:
- SQLite database at `/app/molecules.db` containing molecular integral data
- Source code at `/app/src/` with a buggy fermion-to-qubit encoding and unfinished implementations
- A `Makefile` at `/app/Makefile` with multiple errors preventing `make all` from completing
- Previous run log at `/app/logs/previous_run.log` documenting failures
- Known reference energy at `/app/reference/known_result.txt`

Fix all issues across the Python pipeline, YAML configuration, and Makefile so that `make all` succeeds and produces three correct outputs:

## `/app/db_audit.txt`

Generated by the Makefile's `audit` target, which must use the `sqlite3` command-line tool (not Python) to query `/app/molecules.db`. The file must contain: the full database schema (from `.schema`), row counts for each table, and a listing of every system's name, spatial orbital count, and electron count.

## `/app/results.json`

Generated by the Makefile's `run` target executing the Python pipeline. A JSON object mapping each molecular system name to:

```json
{
  "<system_name>": {
    "ground_state_energy": <float>,
    "n_qubits": <int>,
    "encoding_a_num_terms": <int>,
    "encoding_b_num_terms": <int>,
    "eigenvalues_sorted": [<float, ascending>],
    "spectral_match": <bool>,
    "n_symmetries": <int>,
    "tapered_n_qubits": <int>,
    "tapered_ground_state_energy": <float>
  }
}
```

The two encodings must be **Jordan-Wigner** (`encoding_a`) and **Bravyi-Kitaev** (`encoding_b`).

- `ground_state_energy`: lowest eigenvalue of the qubit Hamiltonian
- `n_qubits`: 2 × number of spatial orbitals
- `encoding_a_num_terms`, `encoding_b_num_terms`: count of Pauli string terms with |coefficient| > 1e-10 from each encoding
- `eigenvalues_sorted`: complete eigenvalue spectrum sorted ascending; all eigenvalues must be real-valued
- `spectral_match`: `true` iff both encodings produce identical eigenspectra (tolerance 1e-8)
- `n_symmetries`: number of independent Z2 Pauli operators that commute with every term in the qubit Hamiltonian
- `tapered_n_qubits`: `n_qubits − n_symmetries`
- `tapered_ground_state_energy`: ground state energy from the symmetry-reduced Hamiltonian, matching the full ground state energy within 1e-6

## `/app/summary.json`

Generated by the Makefile's `summary` target, which must use `jq` (not Python) to extract from `results.json` a flat JSON object:

```json
{
  "<system_name>_energy": <float>,
  "<system_name>_spectral_match": <bool>
}
```

with entries for every system in the results.
