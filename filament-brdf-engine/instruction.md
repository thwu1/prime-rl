The PBR material evaluation library at `/app/` computes physically-based reflectance values using a C shared library called from Python via ctypes. Evaluation configurations are in `/app/config.json` and the complete mathematical specification is at `/app/spec/filament_pbr.md`.

However, the four main evaluation functions — `compute_dfg`, `evaluate_standard_brdf`, `evaluate_clearcoat_brdf`, and `compute_energy_compensation` — are unimplemented stubs returning zeros.

Implement all four evaluation functions according to the specification, resolve any issues in the build configuration and Python FFI layer that prevent correct results, then build and run the pipeline to produce `/app/output.json`. The DFG integration requires careful derivation of the Monte Carlo weight from the importance sampling PDF and the reflection Jacobian — the specification provides the necessary mathematical components but you must determine the correct per-sample weight and normalization factor by analyzing how the provided visibility function relates to the full geometric shadowing term.
