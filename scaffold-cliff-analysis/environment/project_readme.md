# Kinase Inhibitor SAR Campaign

This project contains compound screening data from a kinase inhibitor discovery campaign. The goal is to perform a comprehensive structure-activity relationship (SAR) landscape analysis.

## Project Structure

- `config/` - Pipeline configuration (parameters, thresholds, precision settings)
- `data/` - Raw compound and bioactivity data
- `docs/` - Analysis methodology notes

## Data Notes

- Structural data and bioactivity measurements are stored separately
- Some compounds were measured in multiple assay runs
- Data has not been fully curated — quality issues may exist
- See `data/exclusions.json` for known QC failures
