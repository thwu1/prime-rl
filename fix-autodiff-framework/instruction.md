A reverse-mode automatic differentiation framework is located at `/app/autograd/`. The framework spans a tracing system, a backward pass engine, gradient rules for NumPy operations, and a C shared library that implements a custom numerical primitive with Python `ctypes` bindings.

The framework is non-functional. Attempting to use `from autograd import grad` and compute any gradient fails. There are multiple interrelated defects spanning the build pipeline, the gradient backpropagation logic, and operation coverage. Some failures are immediately visible (crashes, build errors) while others are silent (incorrect numerical results for certain computation graph topologies).

Your task: investigate the entire framework, identify every defect, and produce a fully working system. When complete, `grad(f)(x)` must return correct gradients for scalar-valued functions involving arithmetic, reductions, matrix products, transposition, array indexing/slicing, log-absolute-determinant, linear system solves, the C-accelerated custom operation, and arbitrary compositions of these. All gradients must agree with centered finite-difference approximations to within `1e-4` relative tolerance. Higher-order derivatives (`grad(grad(f))`) must work correctly for element-wise operations.
