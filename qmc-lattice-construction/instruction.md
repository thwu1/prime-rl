A numerical integration toolkit at `/app/` benchmarks Quasi-Monte Carlo (QMC) lattice-rule integration against plain Monte Carlo for a 10-dimensional test function with a known analytical solution. The toolkit has C and Python components but is currently non-functional — `python3 /app/run_benchmark.py` fails due to multiple issues across the codebase.

Make the toolkit produce correct results and deliver these outputs:

1. **`/app/results/benchmark.json`** — generated by a successful run of `python3 /app/run_benchmark.py`, satisfying:
   - QMC integration error below `5e-4` at the largest configured lattice size
   - QMC convergence rate substantially exceeding the MC rate (~0.5)
   - All generating vector components as positive integers in `{1, ..., n-1}`

2. **`/app/results/convergence.png`** — a log-log convergence plot produced by a gnuplot script saved at `/app/results/convergence.gp`, showing both QMC and MC integration error versus number of sample points, with labeled axes and a legend distinguishing the two methods.

3. **`/app/results/benchmark.db`** — a SQLite database containing a table `convergence_results` with columns (`n_points INTEGER, qmc_error REAL, mc_error REAL`), populated with the per-lattice-size convergence data from the benchmark run.
