WCNF Input Format — Weighted Partial MaxSAT (MaxSAT Evaluation Standard)
=========================================================================

The WCNF format is the standard input format for the MaxSAT Evaluation.
It extends the DIMACS CNF format with clause weights and a distinction
between hard and soft clauses.

A Weighted Partial MaxSAT instance consists of:
  - A set of Boolean variables x_1, x_2, ..., x_n
  - A set of weighted clauses over literals of these variables
  - Clauses are either "hard" (must be satisfied) or "soft" (carry a cost
    when unsatisfied)

The objective is to find a truth assignment that satisfies ALL hard clauses
and MINIMIZES the total weight of unsatisfied soft clauses.

File Structure
--------------

1. Comment lines (optional):
   Lines starting with 'c' are comments and should be ignored.

     c This is a comment

2. Problem line (required, exactly one):

     p wcnf <nbvar> <nbclauses> <top>

   - nbvar:     number of Boolean variables (indexed 1 to nbvar)
   - nbclauses: total number of clauses (hard + soft)
   - top:       a weight value strictly greater than the sum of all soft
                clause weights. Clauses with weight >= top are hard.

3. Clause lines (one per clause):

     <weight> <lit_1> <lit_2> ... <lit_k> 0

   - weight: a positive integer. If weight >= top, the clause is hard.
             Otherwise, the clause is soft with the given weight.
   - lit_i:  a non-zero integer. Positive means the variable is true,
             negative means the variable is false. Variable indices
             range from 1 to nbvar.
   - The clause is terminated by 0.

Example
-------

  c Example WCNF instance
  p wcnf 4 5 16
  16 1 -2 4 0
  16 -1 -2 3 0
  8 -2 -4 0
  4 -3 2 0
  3 1 3 0

This instance has 4 variables, 5 clauses, and top weight 16.
- Clauses 1 and 2 are hard (weight 16 = top): must be satisfied.
- Clauses 3, 4, 5 are soft with weights 8, 4, 3 respectively.
- The goal is to find an assignment satisfying both hard clauses while
  minimizing the total weight of unsatisfied soft clauses.

Constraints on Weights
----------------------

  - All weights must be >= 1 and < 2^63.
  - The sum of all soft clause weights must be < 2^64 - 1.
  - top must be strictly greater than the sum of all soft clause weights.

Optimal Cost
------------

The optimal cost of a Weighted Partial MaxSAT instance is the minimum,
over all assignments that satisfy every hard clause, of the total weight
of unsatisfied soft clauses. If no assignment satisfies all hard clauses,
the instance is unsatisfiable.
