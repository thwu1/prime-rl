A raw observational climate dataset at `/app/raw_data/SYNOBS_monthly_2000-2014.nc` contains monthly atmospheric measurements with non-standard variable naming, units, and coordinate conventions, along with CF-convention quality control bit-flag annotations. The CMOR variable specifications (target metadata, derivation requirements for computed quantities) are in `/app/cmor_table.json`, and dataset-level attributes and output conventions are in `/app/cmor_config.yml`.

Write a CMORizer that produces fully CMOR-compliant NetCDF output files (one per target variable) in `/app/output/`. The target variables include both direct conversions (near-surface temperature, precipitation) and physically derived quantities: sea-level pressure must be reduced from surface station pressure using the barometric formula with near-surface temperature and surface orography, and near-surface specific humidity must be computed from dewpoint temperature and surface pressure using standard saturation vapor pressure relations. Quality-flagged observations (any QC bit set in the raw data's bit-field flag variable) must be masked in all outputs. All outputs must conform to CF-1.7 conventions and ESMValTool observational data standards: correct variable and coordinate metadata, CF-compliant coordinate systems and ranges, coordinate bounds, scalar coordinates where specified, float32 data / float64 coordinate types, CMOR-compliant filenames per the config template, and complete global attributes. Run the CMORizer to generate the output.
