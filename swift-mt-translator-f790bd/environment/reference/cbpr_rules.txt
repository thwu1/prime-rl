CBPR+ COMPLIANCE RULES
======================

1. Business Application Header (AppHdr) is mandatory
   - BizSvc must be "swift.cbprplus.02"
   - MsgDefIdr must match the document type (e.g., "pacs.008.001.08")
   - Prty (Priority): HIGH or NORM

2. BIC Format
   - All BICs must be in BICFI format (11 characters)
   - 8-character BICs must be padded with "XXX" (head office branch code)
   - Pattern: [A-Z0-9]{4}[A-Z]{2}[A-Z0-9]{2}[A-Z0-9]{3}

3. UETR (Unique End-to-End Transaction Reference)
   - Mandatory for all payment messages
   - UUID v4 format: xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
   - Sourced from Block 3 {121:} in MT messages

4. Single Transaction per Message
   - NbOfTxs must be "1" for CBPR+ pacs.008/pacs.009
   - Only one CdtTrfTxInf element per message

5. EndToEndId
   - Must always be present
   - Set to "NOTPROVIDED" when no explicit end-to-end identifier from the MT message

6. Account Identification
   - IBAN should be used where applicable (IBAN element)
   - Non-IBAN accounts use Othr/Id element
   - IBAN format: 2 letter country code + 2 check digits + BBAN, length 15-34 chars

7. Character Encoding
   - UTF-8 (Latin characters for CBPR+)
   - XML declaration: <?xml version="1.0" encoding="UTF-8"?>

8. Priority Mapping
   - Block 2 priority indicator 'U' (Urgent) -> Prty = "HIGH"
   - Block 2 priority indicator 'N' (Normal) -> Prty = "NORM"

9. Charge Bearer Mapping
   - MT 71A:BEN -> ChrgBr = "CRED" (creditor bears charges)
   - MT 71A:OUR -> ChrgBr = "DEBT" (debtor bears charges)
   - MT 71A:SHA -> ChrgBr = "SHAR" (charges shared)

10. Settlement Method
    - INDA: Instructed agent settles (no correspondent fields)
    - INGA: Instructing agent settles (field 53 present, no 54)
    - COVE: Cover method (fields 53+54 or 55 present)

11. Date Format
    - MT: YYMMDD (e.g., 230315)
    - MX: YYYY-MM-DD (e.g., 2023-03-15)
    - Year interpretation: 00-79 -> 2000-2079, 80-99 -> 1980-1999

12. Amount Format
    - MT: Comma as decimal separator (e.g., 100000,50)
    - MX: Period as decimal separator (e.g., 100000.50)
    - Currency as XML attribute Ccy on amount elements
