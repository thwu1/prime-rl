AND-OR Closure Size
====================

Problem Statement
-----------------

Given a set A of n distinct non-negative integers, the AND-OR closure of A
is the smallest set B such that:

  - A is a subset of B
  - If x and y are both in B, then (x AND y) is in B
  - If x and y are both in B, then (x OR y) is in B

Here AND and OR denote bitwise operations.

Your task: compute |B|, the number of elements in the AND-OR closure.

Input Format
------------

The first line contains an integer T (1 <= T <= 20), the number of test cases.

For each test case:
  - The first line contains an integer n (1 <= n <= 200000).
  - The second line contains n distinct non-negative integers a_1, a_2, ..., a_n
    (0 <= a_i < 2^40).

The sum of n across all test cases does not exceed 500000.

Output Format
-------------

For each test case, print a single line containing |B|.

Examples
--------

Input:
2
4
0 1 3 5
5
0 1 2 3 4

Output:
5
8

Explanation:

Test case 1: A = {0, 1, 3, 5}.
  Closure B = {0, 1, 3, 5, 7}, so |B| = 5.

Test case 2: A = {0, 1, 2, 3, 4}.
  Closure B = {0, 1, 2, 3, 4, 5, 6, 7}, so |B| = 8.

Notes
-----

A brute-force simulation that repeatedly applies AND and OR to all pairs
can handle small inputs, but will be far too slow for the full constraint
range. An efficient algorithm is required.
