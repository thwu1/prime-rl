The `/app/rust_src/` directory contains Rust source files from the embassy-rs/chiptool project. These define an intermediate representation (IR) for peripheral registers, a name sanitization system with per-category case conversion and Rust keyword escaping, and a transform pipeline that restructures register definitions.

`/app/ir.json` contains a DMA controller peripheral IR with raw unsanitized names (SCREAMING_SNAKE convention). `/app/transforms.yaml` specifies a transform pipeline using chiptool's tagged-union YAML syntax (`!TagName` tags).

Create `/app/transform_engine.py` that reads the input IR and transform configuration, applies each transform in pipeline order faithfully reproducing the Rust source semantics, and writes the transformed IR to `/app/output.json`.

The pipeline begins with `!Sanitize` which normalizes all names using case conversion rules defined in `sanitize.rs` and `mod.rs` (PathSnakePascal for `::` namespace keys, Snake for item/field names, Pascal for enum variants), applies `sanitize_ident` keyword escaping, and deduplicates enum variants. All subsequent transforms reference post-sanitize names. The pipeline includes conditional deletion (`!DeleteFieldsets` with `useless` flag detects semantically empty fieldsets per `delete_fieldsets.rs`, `!DeleteEnums` filters by `bit_size`), field-level renaming (`!RenameFields`), merging, block extraction, and array creation. The `common.rs` module defines `RegexSet`, `match_groups`, and `match_expand` which underpin pattern matching across all transforms. The Rust source files are the sole specification of transform behavior.
