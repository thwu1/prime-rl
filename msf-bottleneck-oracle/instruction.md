A multi-stage data pipeline at `/app/pipeline/` was designed to analyze network topology data stored in a SQLite database at `/app/network/topology.db`. The pipeline is orchestrated by a `Makefile` and uses `sqlite3` CLI for data extraction to JSON, `jq` for measurement aggregation and weight computation, Python for graph analysis, and Graphviz `dot` for topology visualization. The configuration at `/app/network/config.json` describes the required analyses, output formats, and visualization parameters.

The extraction and transformation stages (`make extract`, `make transform`) are implemented. The analysis stage expects a Python script at `/app/pipeline/analyze.py` that reads the intermediate JSON files from `/app/pipeline/build/`, performs graph analysis per the config, writes the results to `/app/results.json`, and generates a DOT graph file for the MSF at `/app/pipeline/build/msf.dot`. The visualization stage renders the DOT file to SVG via `dot`.

Complete the pipeline so that `make -C /app/pipeline all` produces:

1. `/app/results.json` — a JSON object with all analysis fields specified in the config
2. `/app/output/msf.svg` — an SVG visualization of the minimum spanning forest generated by Graphviz, with nodes labeled by hostname and color-coded by site per the visualization config
