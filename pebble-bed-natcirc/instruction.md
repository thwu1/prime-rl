A thermal-hydraulic simulation at `/app/` models natural circulation decay heat removal in a helium-cooled pebble-bed high-temperature gas-cooled reactor (HTGR). The simulation uses a mixed Fortran/Python architecture: packed-bed correlations (Ergun pressure drop, Wakao-Kaguei heat transfer) are implemented in a Fortran shared library (`/app/libpackedbed.so`, source at `/app/src/packed_bed.f90`), called from Python via `ctypes` (see `/app/natcirc_sim/fortran_bridge.py`). Solver runtime options are stored in a SQLite database at `/app/reactor.db`. The Fortran library is built with `make` using the Makefile at `/app/Makefile`.

The simulation has been flagged during independent validation: its output diverges significantly from a qualified reference solver. Reference results are at `/app/validation/reference_results.csv` and a validation summary is at `/app/validation/notes.txt`.
