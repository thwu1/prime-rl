Implement the function `detector_error_model_to_check_matrices` in `/app/dem_converter.py` that converts a `stim.DetectorErrorModel` into sparse matrix representations used by quantum error correction decoders (e.g. BP+OSD).

A skeleton with the `DemMatrices` dataclass definition and function signature is provided at `/app/dem_converter.py`. The function must parse all `error` instructions from the flattened DEM, identify unique hyperedges by their net detector support (the symmetric difference of detector sets across `^`-separated components), extract individual edge decompositions from each component, build binary sparse matrices (`scipy.sparse.csc_matrix` with `uint8` data), and compute prior error probabilities. When multiple error mechanisms target the same net detector set, their probabilities must be combined correctly, reflecting independent error channels composed over GF(2). Setting `allow_undecomposed_hyperedges=False` must raise `ValueError` if any single component involves more than 2 detectors; when `True`, such components are included as hyperedges but omitted from the edge decomposition.

Hyperedge and edge IDs are assigned sequentially in first-encounter order. All six matrix fields plus the priors array in `DemMatrices` must be populated correctly. Instructions of type `detector` or `logical_observable` should be ignored. Stim is pre-installed. Sample DEM files are at `/app/test_data/` for experimentation.
