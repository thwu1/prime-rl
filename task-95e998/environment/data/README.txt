IR Shared Task Evaluation
=========================

Three retrieval systems were evaluated against a test collection
with graded relevance judgments (grades 0-3).

Data files:
  qrels.txt          - Relevance judgments (TREC qrels format)
  system_alpha.run   - System Alpha submission (TREC run format)
  system_beta.run    - System Beta submission
  system_gamma.run   - System Gamma submission

Evaluation was performed using ../eval_pipeline.py.
Results published in ../published_report.json.
