Three IPC-1 (ISCA 2020) instruction prefetcher implementations are in `/app/prefetchers/`: D-JOLT (`DJOLT_prefetcher.cc`), PIPS (`PIPS_prefetcher.cc`), and FNL+MMA (`FNLMMA_prefetcher.cc`). Each operates under a 128 KB hardware storage budget counted in hardware bits, not C++ `sizeof`. The specification is in `/app/spec.md`.

Build `/app/djolt_cost_model.cpp`: a standalone C++ program that takes three command-line arguments (`lr_sets`, `sr_sets`, `extra_sets` — unsigned integers) and prints to stdout the total D-JOLT prefetcher storage in bits for that miss table configuration. All parameters besides set counts (N_Ways, N_Vectors, VectorSize, UpperBitPtrBits, SignatureBits) and all fixed-cost components (signature generators, signature queues, upper bit table, stream prefetcher tables) must use the exact values from the D-JOLT source. Tag bits per table = `SignatureBits − log₂(sets)`. Exit with code 1 if any input is not a power of 2, is below 64, or results in non-positive tag bits. Compile to `/app/djolt_cost_model` with `g++ -std=c++17 -O2`.

Write `/app/budget_calculator.py` to read each prefetcher's C++ source, extract storage-relevant parameters (from `#define`, `constexpr`, budget comments, `size()` methods, and `printf` formulas), compute exact hardware budgets in bits, and output `/app/budgets.json` with keys `"DJOLT"`, `"PIPS"`, `"FNLMMA"`, each containing `"total_bits"` (integer) and `"under_128kb"` (boolean).

Write `/app/sweep.py` to find the D-JOLT miss table configuration `(lr_sets, sr_sets, extra_sets)` — all powers of 2 ≥ 64 with positive tag bits — maximizing `(lr_sets + sr_sets + extra_sets) × N_Ways` total entries under three budget constraints: 128 KB, 160 KB, and 192 KB. Tiebreaker: larger `lr_sets`, then larger `sr_sets`. Output `/app/optimal_configs.json` with keys `"128kb"`, `"160kb"`, `"192kb"`, each containing `"lr_sets"`, `"sr_sets"`, `"extra_sets"`, `"total_entries"`, `"total_bits"`.
