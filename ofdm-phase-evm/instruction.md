Oscillator phase noise in OFDM systems manifests as both a bulk phase rotation common to all subcarriers and as interference between adjacent subcarriers. These two impairment mechanisms have distinct spectral origins and can be separately quantified through simulation.

Build a simulation and analysis tool that quantifies EVM degradation from oscillator phase noise in an OFDM system and decomposes the total impairment into its constituent components.

Examine the `/app/` directory for system configuration and technical specifications defining the required code interfaces and output format. Implement the specified Python modules under `/app/src/` and produce `/app/results.json` with the analysis results.
