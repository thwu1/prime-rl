FRED time series data is at `/app/data/` in mixed formats — some series are plain CSV files, others are inside a SQLite database whose schema is not documented here. Explore the data directory to discover which series live where and understand the database structure before writing analysis code.

Produce three artifacts:

**`/app/results.db`** — SQLite database containing analysis results in these normalized tables:

| Table | Columns |
|---|---|
| `yield_curve_inversions` | `start_date TEXT, end_date TEXT, business_days INTEGER, min_spread REAL` |
| `sahm_rule_episodes` | `start_date TEXT, end_date TEXT, peak_indicator REAL` |
| `real_ffr_extremes` | `type TEXT, date TEXT, value REAL` — exactly two rows with type `'max'` and `'min'` |
| `real_ffr_decades` | `decade TEXT, average REAL` |
| `m2_regime_counts` | `regime TEXT, cnt INTEGER` |
| `m2_growth_extremes` | `type TEXT, date TEXT, value REAL` — exactly two rows with type `'max'` and `'min'` |
| `composite_stress_months` | `date TEXT, score REAL` |

**`/app/build_report.sh`** — Executable shell script that reads from `/app/results.db` using `sqlite3` JSON output mode and assembles the final report with `jq`. Writes `/app/results.json`. Must be idempotent: re-running it regenerates the JSON from the current database state.

**`/app/results.json`** — JSON report generated by executing `build_report.sh`. Top-level keys: `yield_curve_inversions`, `sahm_rule_episodes`, `real_ffr`, `m2_growth`, `composite_stress`.

## Analyses

Round all floats to 4 decimal places. All episode and inversion lists must be sorted chronologically.

**`yield_curve_inversions`** — Sustained inversion episodes from the 10Y-2Y Treasury spread: continuous periods of at least 5 consecutive business days where the spread is negative. Skip missing observations (`.` values) without breaking an ongoing inversion's continuity. Each entry: `{"start_date": "YYYY-MM-DD", "end_date": "YYYY-MM-DD", "business_days": N, "min_spread": X.XXXX}`.

**`sahm_rule_episodes`** — Sahm recession indicator: compute the 3-month simple moving average of the unemployment rate, then subtract the minimum 3-month moving average from the prior 12 observations. A month triggers when this indicator is >= 0.50. Group consecutive triggering months into episodes. Each entry: `{"start_date": "YYYY-MM", "end_date": "YYYY-MM", "peak_indicator": X.XXXX}` where `peak_indicator` is the maximum indicator value within the episode.

**`real_ffr`** — Ex-post real federal funds rate: nominal effective federal funds rate minus year-over-year CPI inflation rate (expressed as a percentage). Output: `{"max": {"date": "YYYY-MM", "value": X.XXXX}, "min": {"date": "YYYY-MM", "value": X.XXXX}, "decade_averages": {"1950s": X.XXXX, ...}}`. Include only decades that have data.

**`m2_growth`** — Year-over-year M2 money supply growth rate, classified into regimes: `contraction` (<0%), `low` ([0%, 5%)), `moderate` ([5%, 10%)), `rapid` ([10%, 15%)), `extreme` (>=15%). Output: `{"regime_counts": {"contraction": N, ...}, "max_growth": {"date": "YYYY-MM", "value": X.XXXX}, "min_growth": {"date": "YYYY-MM", "value": X.XXXX}}`.

**`composite_stress`** — Composite stress index from four z-scored (population standard deviation) monthly series: monthly-averaged Treasury spread, 3-month unemployment rate change, real FFR, and M2 YoY growth rate. Formula: `stress = -spread_z + unemp_change_z + real_ffr_z - m2_growth_z`. Report only months with score > 2.0, sorted chronologically: `{"stress_months": [{"date": "YYYY-MM", "score": X.XXXX}, ...], "max_stress": {"date": "YYYY-MM", "score": X.XXXX}, "count": N}`.
