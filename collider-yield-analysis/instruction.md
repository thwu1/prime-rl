A multi-stage event selection pipeline for a particle physics search (vector-like top quarks decaying to *tH* in semi-leptonic final states) is at `/app/pipeline/`, orchestrated by a `Makefile`. The first stage (`extract.py`) reads simulated events from a ROOT file at `/app/data/signal.root` using `uproot` and writes extracted data to `/app/intermediate/events.npz`. The second stage (`analyze.py`) applies event selection cuts using calibration parameters queried from a SQLite database at `/app/calibration/calib.db`, computes systematic variations, and writes results. The full analysis specification is at `/app/paper/analysis.md`. Expected SM background yields are at `/app/data/background_yields.json`.

The pipeline contains implementation errors across its stages that produce incorrect signal yields. Using the analysis paper and calibration database as ground truth, identify and fix all bugs. Then ensure the corrected pipeline computes systematic uncertainty variations (JES and b-tagging, with parameters from the calibration database) and the expected Asimov discovery significance.

Run the pipeline via `make -C /app/pipeline all` and write all results to `/app/results/results.yaml`, replacing every null value: corrected nominal signal yields, JES up/down yields, b-tag up/down yields, total per-bin systematic uncertainty, and the scalar expected significance.
