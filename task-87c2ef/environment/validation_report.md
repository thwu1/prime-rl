# Validation Report — Evaluation Pipeline Discrepancies

The following discrepancies were identified when comparing pipeline output
against manually verified reference values.

## Issue 1: Missing Submission Handling (team_e, segmentation)

team_e did not submit segmentation predictions. The pipeline reports their
GTVn aggregated F1 as 1.0 (perfect detection). The ground truth contains
patients with lymph node lesions that were not detected, so a missing
submission should reflect zero detection performance. Expected: all three
segmentation metrics for team_e should be 0.0.

## Issue 2: GTVn Dice Similarity Assessment

The GTVn DSC values produced by the pipeline diverge from validated
reference values. The population-level score does not correctly reflect the
intended volume-aware pooling methodology and appears to overweight patients
with small or absent lymph node lesions.

## Issue 3: Survival Prognosis Concordance

Teams whose predicted risk scores strongly correlate with actual patient
outcomes are receiving lower concordance scores than teams with weaker
predictions. The risk-to-outcome comparison appears to be oriented
incorrectly. Additionally, certain comparable patient pairs appear to be
excluded from the concordance calculation — specifically pairs where
patients share the same event time but have different censoring status.

## Issue 4: Ranking Tie Resolution

In several sub-rankings where teams achieve identical metric values or
Borda sums, the pipeline assigns distinct sequential ranks instead of the
expected fractional averaging. For example, two teams with identical GTVn
Borda sums should receive the same fractional rank, not consecutive integer
ranks.

## Issue 5: Bootstrap Reproducibility

Bootstrap confidence intervals generated by the pipeline do not match
reference intervals. Verify that the random seed used by the pipeline is
consistent with the protocol specification (seed 12345, per the study
protocol documentation).

## Expected Structural Properties

- team_e: gtvp_mean_dsc = 0.0, gtvn_agg_dsc = 0.0, gtvn_agg_f1 = 0.0
- All teams must have valid (non-NaN) values for all metrics and rankings
- Fractional ranks must be used for all sub-rankings
- C-index values should fall in [0, 1] and reflect actual predictive quality
- Bootstrap CIs must be reproducible with seed 12345
