A robotics simulation protocol engine at `/app/engine.py` implements the `simulation_interfaces` v2.1.0 ROS 2 standard — a cross-simulator API for world lifecycle management, entity CRUD, state machine control, physics stepping, and scoped resets. The implementation was auto-translated from a C++ reference backend, introducing multiple protocol conformance bugs: incorrect error code precedence, missing validations, wrong operator semantics, and silent state corruption through reference aliasing.

Diagnose and fix all conformance bugs so the engine fully complies with the specification. The Interface Definition Language files at `/app/idl/messages.idl` and `/app/idl/services.idl` are the authoritative protocol specification — inline comments define all behavioral contracts including error codes, validation rules, state machine transitions, and semantic constraints. Python type bindings for all IDL types are in `/app/interfaces.py`.

A diagnostic conformance probe is available at `/app/run_checks.py`. It outputs structured JSON with per-probe pass/fail results. The probe tests against its own coded expectations — the IDL specification is authoritative when probe results and specification disagree.
