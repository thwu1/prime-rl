arkv - Custom Archive Tool
Version 2.1.0

Usage: arkv <command> [args...]

Commands:
  create <archive> <files...>  Create a new archive from given files
  list <archive>              List entries in an archive
  extract <archive> [dir]     Extract archive contents to directory (default: .)

Options:
  --help     Show this message
  --version  Show version info

Archive format is proprietary. Created archives use the .arkv extension
by convention.
