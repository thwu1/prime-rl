SYSTEM OVERVIEW
===============
Server for Freedom Island's road speed enforcement network. Coordinates
between ANPR (Automatic Number Plate Recognition) cameras and ticket
dispatchers over TCP connections using a binary protocol. The server must
handle concurrent clients.

Cameras are positioned at known mile markers on numbered roads. Each
camera knows its road number, mile position, and the road's speed limit.
Cameras report vehicle number plate observations with timestamps.

When a vehicle is detected travelling in excess of the speed limit
between two observation points, the server generates a ticket and sends
it to a dispatcher responsible for that road.

Roads are identified by numbers 0-65535. Positions are in integer miles
from the start of the road. Number plates are uppercase alphanumeric
strings. Timestamps are unsigned Unix timestamps (seconds since epoch).


DATA TYPES
==========
All multi-byte integers are unsigned, network byte-order (big endian).

  u8    Unsigned 8-bit integer (1 byte)
  u16   Unsigned 16-bit integer (2 bytes)
  u32   Unsigned 32-bit integer (4 bytes)
  str   Length-prefixed string: u8 length followed by that many ASCII bytes

Examples:
  u16 value 123  ->  00 7b
  u32 value 1000 ->  00 00 03 e8
  str "UN1X"     ->  04 55 4e 31 58
