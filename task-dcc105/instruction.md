A combined heat and power (CHP) plant's steam/water distribution network is instrumented with 20 sensors (12 flow meters, 8 thermocouples). The physical model of the network — defining all conservation constraints and the thermodynamic property function — is specified in `/app/plant_model.mo` (OpenModelica Modelica language format). Sensor readings with their measurement uncertainties are in `/app/measurements.csv` (semicolon-delimited; columns: Variable Name, Measured Value, Half Width Confidence Interval at 95% level). Inter-sensor correlation coefficients are in `/app/correlations.csv` (sparse lower-triangular semicolon-delimited format; the header row `Sxy` labels the column variables; entries are dimensionless correlation coefficients between variable pairs; empty cells denote zero correlation).

Some sensors in this network have systematic biases (gross errors). Perform a complete data reconciliation of this network according to VDI 2048: produce adjusted measurements that satisfy every physical constraint from the Modelica model, detect which sensors are faulty using statistical hypothesis testing (both a global validation test and per-sensor local tests), and compute reconciled measurement uncertainties.

Write results to:
1. `/app/reconciled_values.csv` — semicolon-delimited with columns: `Variable Name;Measured Value;Reconciled Value;Measured HWCI;Reconciled HWCI;Local Test Value;Local Test Result` where Local Test Result is `TRUE` (sensor passes, non-faulty) or `FALSE` (sensor fails, faulty)
2. `/app/test_results.json` — JSON object with keys: `global_test` (object containing `J_star`, `chi_square_critical`, `degrees_of_freedom`, `result`), `faulty_sensors` (list of variable names that fail the local test), `num_iterations`, `converged` (boolean)
