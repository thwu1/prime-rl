An optimization pipeline for constrained 2D rectangle packing is configured at `/app/`. Given N companies (50–200) on a 10000×10000 grid, each with a desired location and area, assign non-overlapping axis-aligned rectangles maximizing average satisfaction based on point containment and area match. Full specification in `/app/problem.md`.

The environment includes pre-generated test cases at `/app/test_cases/` spanning five distribution categories (uniform, spatially clustered, near-collinear, extreme area ratios, and half-plane asymmetric), a scorer at `/app/scorer.py`, and a Makefile-driven benchmarking pipeline (`make benchmark`, `make analyze`, `make by-type`, `make worst`) that evaluates solver performance and tracks per-case experiments in an SQLite database at `/app/results.db`. The benchmark runner at `/app/benchmark.py` produces JSON summaries suitable for processing with standard JSON tools.

Create `/app/solver.py` (stdin → stdout) achieving average satisfaction ≥ 0.75 across all provided test cases. The adversarial distributions require understanding the interplay between containment constraints, area-matching objectives, and partition geometry — naive axis-aligned partitioning strategies will not suffice.
