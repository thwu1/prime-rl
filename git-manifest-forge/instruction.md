A git repository at `/app/repo/` was generated by a buggy tool. It should contain a valid 2-commit history on branch `main`, but multiple corruption issues prevent it from passing integrity checks.

Write a repair script at `/app/repair.py` that fixes the repository in-place. The script must use only Python's standard library — no git libraries (`dulwich`, `gitpython`, `pygit2`) and no invocations of `git` via `subprocess`, `os.system`, or similar.

After running `python3 /app/repair.py`, the repository must satisfy:

- `git fsck --full --strict` exits cleanly with no errors
- `git status --porcelain` produces no output
- `git log --oneline` shows exactly 2 commits
- All original commit metadata (authors, timestamps, messages) is preserved
