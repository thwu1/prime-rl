# pyanalysis-tools

Lightweight statistical analysis and data processing utilities for Python.

## Installation

```bash
pip install pyanalysis-tools
```

## Usage

```python
from pyanalysis_tools.stats import mean, median, std_dev

data = [10, 20, 30, 40, 50]
print(mean(data))     # 30.0
print(median(data))   # 30
print(std_dev(data))  # 15.81...
```
