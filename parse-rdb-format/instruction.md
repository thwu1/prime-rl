A Redis RDB (database dump) file is located at `/app/data.rdb`. It was generated by Redis 7.x and contains key-value data across multiple databases with various internal encoding types: raw strings, integer-encoded strings, LZF-compressed strings, listpacks, quicklists, and intsets.

Build `/app/rdb_parser.py` that reads this binary file and outputs JSON to stdout.

Usage: `python3 /app/rdb_parser.py /app/data.rdb`

The output must be a JSON object with a `databases` key mapping database number strings to objects. Each database object maps key names to entries containing `type` (one of `string`, `hash`, `list`, `set`, `zset`), `value`, and optionally `expiry_ms` (absolute Unix millisecond timestamp, only present for keys that have an expiration set).

Value formats: `string` type uses a JSON string (even for integer-encoded values like `42`, output `"42"`); `hash` uses a JSON object mapping field names to string values; `list` uses an ordered JSON array of strings; `set` uses a JSON array of string members; `zset` uses a JSON array of `[member_string, score_number]` pairs.

Parse the RDB binary format from scratch using only Python standard library modules. Do not use any Redis client libraries, RDB parsing libraries, redis-server, or redis-cli in your solution.
