================================================================================
1. Overview
================================================================================

Nasdaq TotalView ITCH is a direct data feed product offered by The Nasdaq
Stock Market, LLC. TotalView ITCH provides order-level market data for all
exchange-listed securities traded via the Nasdaq execution system.

The feed uses a series of messages to track the life of customer orders,
report trade executions, disseminate net order imbalance data, and
communicate administrative information such as trading halts and symbol
directories.

TotalView ITCH carries order level data for NYSE, NYSE American, NYSE Arca,
and BATS listed securities as well as Nasdaq-listed securities.

================================================================================
2. Architecture
================================================================================

The TotalView ITCH feed is composed of a series of sequenced messages. Each
message is variable in length based on the message type.

Messages are typically delivered using a higher-level transport protocol that
handles sequencing and delivery guarantees, such as SoupBinTCP or MoldUDP64.

Instruments are identified by a Stock Locate code -- a low-lying integer
assigned dynamically each day via the Stock Directory message. The Stock
Locate code appears in all messages at the same position (offset 1, 2 bytes)
to support efficient filtering.

================================================================================
3. Data Types
================================================================================

All integer fields are unsigned, big-endian (network byte order) encoded.

All alpha fields are left-justified ASCII, padded on the right with spaces.

Price (4):  Unsigned 32-bit integer with 4 implied decimal places.
            The stored value equals price * 10000.
            Example: 150.2500 is stored as 1502500.
            Maximum value: 200,000.0000.

Price (8):  Unsigned 64-bit integer with 8 implied decimal places.
            Used exclusively for MWCB Decline Level messages.

Timestamp:  Unsigned 48-bit (6-byte) integer representing nanoseconds
            since midnight Eastern Time. All messages carry a timestamp
            at offset 5 with length 6.

Stock:      8-byte Alpha field containing the security symbol,
            right-padded with spaces.

================================================================================
4. Message Formats
================================================================================

Each message begins with a 1-byte Message Type field at offset 0, followed
by common header fields (Stock Locate, Tracking Number, Timestamp) and then
type-specific payload fields.

--------------------------------------------------------------------------------
4.1 System Event Message
    Message Type: 'S'    Total Length: 12 bytes
--------------------------------------------------------------------------------

  Offset  Length  Type     Field
  ------  ------  -------  ----------------------------------------
  0       1       Alpha    Message Type = 'S'
  1       2       Integer  Stock Locate (always 0)
  3       2       Integer  Tracking Number
  5       6       Integer  Timestamp
  11      1       Alpha    Event Code

  Event Codes:
    'O' = Start of Messages (first message of trading day)
    'S' = Start of System Hours
    'Q' = Start of Market Hours
    'M' = End of Market Hours
    'E' = End of System Hours
    'C' = End of Messages (last message of trading day)

4.13 Order Executed Message
    Message Type: 'E'    Total Length: 31 bytes
--------------------------------------------------------------------------------

  Offset  Length  Type     Field
  ------  ------  -------  ----------------------------------------
  0       1       Alpha    Message Type = 'E'
  1       2       Integer  Stock Locate
  3       2       Integer  Tracking Number
  5       6       Integer  Timestamp
  11      8       Integer  Order Reference Number
  19      4       Integer  Executed Shares
  23      8       Integer  Match Number

  Sent when a displayable order on the book is executed in whole or
  part. The execution price equals the display price of the original
  order. If the remaining order quantity reaches zero, the order is
  implicitly removed from the book.

  Match Number uniquely identifies this execution. It may be
  referenced by a subsequent Broken Trade message.

4.14 Order Executed With Price Message
    Message Type: 'C'    Total Length: 36 bytes

  Offset  Length  Type     Field
  ------  ------  -------  ----------------------------------------
  0       1       Alpha    Message Type = 'C'
  1       2       Integer  Stock Locate
  3       2       Integer  Tracking Number
  5       6       Integer  Timestamp
  11      8       Integer  Order Reference Number
  19      4       Integer  Executed Shares
  23      8       Integer  Match Number
  31      1       Alpha    Printable
  32      4       Price(4) Execution Price

  Sent when a non-displayable order on the book is executed at a
  price different from the initial display price.

  Printable:
    'Y' = Printable (counted in consolidated volume / last sale)
    'N' = Non-Printable (not counted in consolidated volume)

  If remaining order quantity reaches zero, the order is implicitly
  removed from the book.

    Message Type: 'X'    Total Length: 23 bytes

  ------  ------  -------  ----------------------------------------

  1       2       Integer  Stock Locate

  5       6       Integer  Timestamp
  11      8       Integer  Order Reference Number

4.17 Order Replace Message
    Message Type: 'U'    Total Length: 35 bytes
--------------------------------------------------------------------------------

  Offset  Length  Type     Field
  ------  ------  -------  ----------------------------------------
  0       1       Alpha    Message Type = 'U'
  1       2       Integer  Stock Locate
  3       2       Integer  Tracking Number
  5       6       Integer  Timestamp
  11      8       Integer  Original Order Reference Number
  19      8       Integer  New Order Reference Number
  27      4       Integer  Shares
  31      4       Price(4) Price

  The Replace message removes the original order from the book and
  creates a new order with the specified new reference number, shares,
  and price. The new order INHERITS the buy/sell indicator, stock
  symbol, and MPID attribution from the original order.

  Note: The original order's remaining shares are irrelevant -- the
  replacement order gets exactly the shares specified in this message.
  The new reference number must be used for all subsequent operations
  on this order.
