The block-quantized INT8 matrix multiplication library at `/app/` performs tiled matmul in either symmetric or asymmetric quantization, selected uniformly across all tiles via `quantized_matmul`. The header `/app/include/qmatmul.h` declares `adaptive_quantized_matmul` — a variant that independently selects the optimal quantization mode per tile — but its implementation in `/app/src/qmatmul.c` is a stub returning -1.

Implement `adaptive_quantized_matmul`. It must produce correct results for arbitrary matrix dimensions and block sizes, achieve lower error than uniform symmetric quantization on biased distributions, and report per-mode tile counts via the `stats` parameter. The library specification is in `/app/SPEC.md`. Validate with `python3 /app/validate.py` after rebuilding with `make` in `/app/`.
