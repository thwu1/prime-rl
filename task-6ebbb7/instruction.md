You are given experimental boundary layer velocity profile data and computational fluid dynamics (CFD) skin friction coefficient (Cf) results from two RANS turbulence models (Spalart-Allmaras and Menter k-omega SST) run on four systematically-refined grids for the NASA 2D bump-in-channel verification case.

Build a post-processing analysis pipeline that produces four JSON result files in `/app/results/`:

**`/app/results/bl_analysis.json`** — Boundary layer integral analysis of the experimental velocity profile in `/opt/cfd_data/data/experimental/bl_profile.dat`. Compute displacement thickness (`delta_star`), momentum thickness (`theta`), and shape factor (`shape_factor`) via numerical integration (trapezoidal rule, including wall contribution from y=0 to first data point). Determine the friction velocity (`u_tau`) by fitting the near-wall velocity data (y <= y_max_for_fit) to Spalding's law of the wall — the implicit composite profile `y+ = u+ + exp(-kappa*B)*[exp(kappa*u+) - 1 - kappa*u+ - (kappa*u+)^2/2 - (kappa*u+)^3/6]` — by minimizing the sum of squared residuals between measured y+ and Spalding-predicted y+. Compute skin friction coefficient `Cf = 2*(u_tau/U_e)^2`. Flow parameters and wall model constants are in `/opt/cfd_data/config.json`.

**`/app/results/grid_convergence_sa.json`** and **`/app/results/grid_convergence_sst.json`** — Grid convergence studies for each turbulence model. CFD data is in `/opt/cfd_data/data/cfd/bump_cf_sa.csv` and `bump_cf_sst.csv`. At each x-station, apply Richardson extrapolation using the three finest grids (grid1=finest through grid3) to compute the observed order of accuracy (`p`), the grid-independent extrapolated solution (`f_ext`), and the Grid Convergence Index (`gci_fine` and `gci_medium`) with safety factor Fs=1.25. Use all four grids to compute an asymptotic range indicator (`asymp_ratio`): the ratio of GCI_medium to (r^p * GCI_fine), which should approach 1.0 for solutions in the asymptotic range. Output format: `{"stations": [{"x": ..., "p": ..., "f_ext": ..., "gci_fine": ..., "gci_medium": ..., "asymp_ratio": ...}, ...]}`.

**`/app/results/model_comparison.json`** — Quantitative comparison of the extrapolated (grid-independent) Cf values between SA and SST models. Compute the relative difference at each station as `|sa_ext - sst_ext| / max(|sa_ext|, |sst_ext|) * 100`, plus aggregate metrics `rms_rel_diff_pct` and `max_rel_diff_pct` (in percent), and identify `max_diff_station`.

Refer to `/opt/cfd_data/config.json` for physical constants (von Karman constant kappa, Spalding B, kinematic viscosity nu, edge velocity U_e, grid refinement ratio r=2.0, safety factor Fs=1.25, y_max_for_fit for Spalding fitting).
