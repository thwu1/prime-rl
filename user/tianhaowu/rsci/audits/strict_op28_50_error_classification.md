# Strict OP28 50-trajectory manual classification

This is a diagnostic, error-enriched sample, not a prevalence sample. The
selection contains 50 distinct OP28 prompts whose trajectories all passed the
released strict verifier:

- 30 with an independently evaluable numeric contradiction, balanced 10/10/10
  across the zoo, movie, and school templates;
- 10 with one or more extra parsed nodes and no numeric contradiction;
- 10 with a stateful symbol-substitution contradiction but no numeric
  contradiction or extra node.

The deterministic selection and full model/canonical dossier are generated by
`audit_strict_trajectory_errors.py`. The preserved dossier is
`/checkpoint/ram-h100-2/tianhaowu/rsci/audits/strict-op28-50-error-trajectories-v1/dossier.md`

## Primary classifications

| Primary class | Count | Meaning |
| --- | ---: | --- |
| Required-path arithmetic contradiction / gold-value injection | 22 | A required equality is numerically false, but its final literal is the gold node value or answer. |
| Wrong arithmetic in an unchecked extra subgraph | 8 | The required path is correct, while an unnecessary extra node contains false arithmetic. |
| Unsupported extra node or equation | 8 | The response invents a quantity/equation absent from the problem and the verifier ignores it. |
| Symbol aliasing or stale-variable reuse in the required trace | 11 | One letter is overwritten and then used simultaneously with its old and new meanings; the numeric literals conceal the contradiction. |
| Semantically valid extra distractor only | 1 | The response computes a correct but unnecessary prompt-defined distractor. |

Thus 49 of 50 deliberately selected cases contain a semantic defect. This
ratio cannot be extrapolated to the full 50K shard because the sample was
conditioned on automated defect indicators.

## Mechanism

The strict parser gathers dependency letters from the complete equality chain
but uses only the final equality segment as the node value. It also permits
extra predicted graph nodes. Therefore a response can preserve the expected
node names, dependency set, final node literals, and answer while its written
arithmetic or symbol semantics are false. Canonical GSM-Infinite targets avoid
all four observed defects: value injection, wrong extra arithmetic,
unsupported nodes, and mutable-symbol aliasing.
