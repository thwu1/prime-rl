# Slowly Convergent Alternating Series

Compute the alternating series whose term function is defined in the data file referenced by the challenge configuration.

The series converges conditionally with extremely slow decay of terms — slower than any power of 1/n. Direct partial summation will not yield sufficient precision within any practical number of terms. Series acceleration techniques are essential.

## Output Format

Write a single value to the output file specified in challenge.json, in plain decimal or scientific notation.
