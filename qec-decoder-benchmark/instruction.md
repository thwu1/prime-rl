Create a Python pipeline at `/app/qec_pipeline.py` that benchmarks quantum error correction decoders using the Stim quantum circuit simulator and the Tesseract decoder library. The pipeline reads circuit parameters from `/app/data/circuit_config.json` and writes results to `/app/output/`.

## Required Outputs

**`/app/output/processed.dem`** — The detector error model derived from the configured circuit (with `decompose_errors=False`), with indistinguishable errors merged via `common.merge_indistinguishable_errors` and zero-probability errors removed via `common.remove_zero_probability_errors`. Write as a valid Stim DEM string.

**`/app/output/cross_validation.json`** — Cross-validation of the Tesseract (A*) decoder against the Simplex (ILP) decoder on the configured circuit. Sample 500 shots with seed 42 using `compile_detector_sampler`. Decode each shot with both decoders (Tesseract: `det_beam=10`, `beam_climbing=True`; Simplex: default config, call `init_ilp()` before decoding). After calling `decode()`, access `predicted_errors_buffer` and pass it to `cost_from_errors()` for each decoder. Compare costs with tolerance 1e-6. Count logical errors by comparing decoder observable predictions with actual observable flips. Skip shots where Tesseract sets `low_confidence_flag`. JSON keys: `total_shots` (500), `cost_matches`, `cost_mismatches`, `logical_errors_tesseract`, `logical_errors_simplex`.

**`/app/output/error_rates.json`** — For each combination of code distance d in {3, 5, 7} and physical error rate p in {0.05, 0.15, 0.2}: generate a `repetition_code:memory` circuit with `rounds = 3*d` and `after_clifford_depolarization=p`. Sample 2000 shots (seed 12345). Decode with Tesseract (`det_beam=5`, `decompose_errors=True` on the DEM). Use `decode_batch` for efficiency. Compute per-round logical error rate: `R_round = 0.5 * (1 - (1 - 2*R)^(1/rounds))` where R = errors/shots. Edge cases: R=0 → R_round=0; R≥0.5 → R_round=0.5. JSON list of 9 objects: `distance`, `physical_error_rate`, `logical_error_rate_per_shot`, `logical_error_rate_per_round`, `num_shots`, `num_rounds`, `num_errors`.

**`/app/output/threshold.json`** — Pseudo-threshold estimate: the physical error rate where the d=3 and d=5 per-round logical error rate curves cross, found by linear interpolation between adjacent (p) points in the error_rates data where the sign of `(d3_rate - d5_rate)` changes. JSON key: `threshold_estimate`.
