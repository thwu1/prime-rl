Metavariables:
- x ranges over sort id
- v ranges over sort literal
- q ranges over sort bool
- a ranges over sort aexp
- b ranges over sort bexp
- s ranges over sort stmt
- SL ranges over sort stmt_list and SL ::= ε       // Empty stmt_list
                                        | s :: SL' // head and tail

Configuration:
- Store σ := { id ↦ literal }
- Control stack χ := ε       // Empty stack
                  | s :: χ'  // s is statement on top of stack
- configuration := ⟨operation,σ,χ⟩
- terminal configurations :=⟨ε,σ,χ⟩| ⟨halt,σ,χ⟩| ⟨ERROR,σ,χ⟩

Metafunctions:
- push(s, χ) := s :: χ
- pop(s :: χ) := χ   // χ ≠ ε
- top(s :: χ) := s
- top(ε) := ε
- SL1 ++ SL2 :=
    if SL1 = ε then SL2
    else if SL1 = s :: SL1' then s :: (SL1' ++ SL2)

Transition format:
- single-step transition := ⟨o,σ,χ⟩ → ⟨o',σ',χ'⟩, o evaluates to o' in exactly one step while updating store from σ to σ' and loop stack from χ to χ'
