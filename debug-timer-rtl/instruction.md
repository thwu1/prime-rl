Eight mutant RTL variants, each containing exactly one distinct functional bug, are at `/app/mutants/mutant_1.v` through `/app/mutants/mutant_8.v`.

Write a Verilog testbench at `/app/tb/tb_verify.v` that passes every check against the golden RTL and produces at least one `[FAIL]` line when simulated against each mutant, achieving 100% mutation kill score. The testbench must contain at least 15 individually reported `[PASS]`/`[FAIL]` checks that collectively exercise all timer behaviors in the spec: prescaler division at multiple ratios, compare-match with and without auto-reload across both channels, interrupt flag write-1-to-clear semantics, input capture on both edge polarities, IRQ enable masking, counter overflow wrapping, and register isolation between channels. Print `ALL TESTS PASSED` when every check succeeds and `SOME TESTS FAILED` otherwise. End simulation with `$finish`.

Use `/app/sim.sh` to compile and run against the golden RTL. Use `/app/run_mutation_test.sh` to evaluate mutation coverage across all eight variants. Do not modify files outside `/app/tb/`.
