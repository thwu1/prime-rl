A 20-player chess tournament governed by the FIDE Dubov Swiss System has completed 5 of 7 rounds. The tournament record is at `/app/tournament.trf` (TRF16 format). The CPPDubovSystem pairing engine source is at `/app/CPPDubovSystem/`.

Produce `/app/results.json` containing full standings with FIDE-regulation tiebreakers, color allocation state for every player, and the next round's pairings generated by the engine. All tiebreaker computations and color preference determinations must conform to current FIDE Swiss system regulations.

```json
{
  "standings": {
    "<player_id>": {
      "name": "<string>",
      "rating": <int>,
      "points": <float>,
      "buchholz_cut1": <float>,
      "sonneborn_berger": <float>,
      "aro": <int>,
      "color_balance": <int>,
      "due_color": "<white|black|none>"
    }
  },
  "standings_order": ["<player_id>", ...],
  "tournament_params": {
    "total_rounds": <int>,
    "completed_rounds": <int>
  },
  "next_round_pairings": [
    {"white": <int>, "black": <int>}
  ]
}
```

Player IDs are string keys matching TRF starting rank numbers (`"1"` – `"20"`). `standings_order` ranks all 20 players by points, then Buchholz Cut 1, then Sonneborn-Berger (all descending). `aro` values are integers. Pairings must match the CPPDubovSystem engine output exactly; `white`/`black` are integer player IDs.
