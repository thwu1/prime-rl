A set of 8 RSA public keys is provided at `/app/keys.json`. Each entry contains a key identifier, a hex-encoded RSA modulus `n`, and the public exponent `e` (hex-encoded as `"10001"`).

Some of these keys were generated by a flawed algorithm that produces primes of the form `p = g^a mod M`, where `g` is a fixed generator and `M` is a product of specific small primes. The multiplicative order of `g` modulo `M` is smooth, which constrains the residues of `n` modulo each small prime factor of `M` to lie within a small subgroup generated by `g`. This algebraic structure makes the keys vulnerable to efficient factoring via discrete-log enumeration over the candidate exponents.

Your task:

1. Determine which keys are vulnerable by analyzing the distribution of `n mod p` for small primes `p` and identifying which moduli have anomalously restricted residue patterns consistent with a specific generator and set of characteristic primes.

2. For each vulnerable key, recover the complete prime factorization `n = p * q` by exploiting the constrained structure.

3. Write the results to `/app/results.json` in the following format:

```json
{
  "key_0": {"vulnerable": true, "p": "decimal_string", "q": "decimal_string"},
  "key_1": {"vulnerable": false},
  ...
}
```

Every key in `keys.json` must appear in the results. For vulnerable keys, `p` and `q` must be provided as decimal strings satisfying `p * q == n` with both `p` and `q` prime.
